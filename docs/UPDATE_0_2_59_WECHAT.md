# StepX Companion 0.2.59 更新

用 STEPX 手机的朋友，可以试试这个开源桌面伴侣：把手机里的 AI、文件和背屏搬到电脑上用。

这次升级，先看两个新功能👇

🛍️ 应用商店
在电脑上找应用、看详情和截图，下载后直接安装到手机，还能检查应用更新。

📺 局域网投屏
手机连着电脑，同一个 Wi-Fi 下，其他设备扫码或打开链接就能看手机画面。默认只观看，也可以开启远程控制。

第一次了解？它还能帮你做这些：

💬 直接与手机 Amoo 对话，用手机的模型与 Token 权益处理资料、生成图片和完成工作。
📁 手机与电脑互传文件，不用反复发给自己。
💾 电脑保存照片、视频等原件，为手机腾空间；确认迁移规则后自动执行，需要时可取回。
🎮 设置背屏动画、把图片转成像素图，还能玩左右倾斜控制的背屏小游戏。
🧰 集成 Google Play 安装与常用手机管理工具。

本次也改进了投屏传输、设备数据显示和安装校验，使用反馈更清楚。

🎬 3 分 9 秒女声介绍，完整界面展示，新用户也能看懂。

支持 Windows、macOS、Linux，主要适配 STEPX Neo / PZ261A。部分功能依赖手机固件与权限；安装 Google Play 不等于获得设备认证。
