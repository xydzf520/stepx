## 真实画面与使用条件

所有产品镜头都在 **0.2.180 原生客户端**重新录制，使用独立配置、状态和显式演示资料；最新首页没有复用旧版画面。操作直接点击原生控件。弹窗是独立原生窗口，剪辑时保留主界面上下文，再展示卡片和菜单。画面上的标题、字幕与点击提示属于视频注释。

- 文件列表使用本地演示文件和手机来源的演示元数据；展示查看与传输入口，没有把演示记录当成真实传输成功。
- 电话镜头展示未接记录、筛选与回拨入口，没有伪造真实来电、接通或音频成功。电脑双向音频目前以支持手机、固件与 Linux 的实测为准。
- Amoo 与作品使用已有演示会话和成果；没有把预置资料剪成现场模型生成。AI 调用与通知回复仍依赖实际接口和账号权限。
- 连接镜头展示引导入口与步骤，不替代手机首次授权；消息范围以已同步内容为准。
- 性能段展示实际布局操作，剪辑速度不是性能证据；量化结果和限制见[性能说明](../PERFORMANCE.md)。

录制与公开输出不使用真实聊天、通讯录、私人文件、设备记录或开发机截图。内部原始状态、配置与操作日志不随公开媒体发布。发布截图的来源见 [0.2.180 素材清单](../../desktop/assets/release-notes/0.2.180/sources.json)。

## 配色、配音与验收

浅色底 `#FAFAFB`、深色文字 `#18181B`、辅助灰 `#71717A`、细线 `#E5E5EA`，蓝色与青绿色强调操作和状态；保留客户端红包与胶囊的语义色。标题和字幕有独立安全区域，主体界面等比展示。

成片为 **1600 × 1040、24 fps、H.264 / YUV420p、AAC 单声道 24 kHz**，含烧录字幕和独立 SRT，支持渐进播放。旁白使用 Microsoft Edge 在线 TTS `zh-CN-XiaoxiaoNeural`，语速 `+5%`；这是视频合成配音，不是手机端侧语音功能展示。

实际 MP4 已完成完整解码、连续黑帧、音频削波和字幕时轴检查，抽帧来自最终成片。25 段实际旁白经本地 ASR 转写核对，另复核 6 段版本号、品牌与英文缩写读音；逐词时间与配音稿一致。此处不将自动转写核对表述为人工听音。
