## 视觉规范

沿用客户端浅色底（`#FAFAFB`）、深色主文字（`#18181B`）、灰色辅助文字（`#71717A`）和细分隔线（`#E5E5EA`）；蓝色（`#3B82F6`）与青绿色（`#0D9488`）只强调行动与状态。保留原生胶囊、红包的语义色，不加装饰性渐变或厚重阴影。章节标题与字幕预留固定安全区域，界面等比展示，过渡约 0.33 秒。
