# StepX Companion 0.2.182

**本次更新：0.2.181 → 0.2.182（2026-11-08）。累计功能范围：0.2.60 → 0.2.182。**

## 弹窗直接清空，消息仍然保留

右下角弹窗顶部从左到右为 **清空、菜单、关闭**。点击“清空”即可收起当前和排队的普通弹窗，无需再展开菜单；消息中心历史、未读状态、之后的新提醒，以及正在进行的通话均保留。“关闭”仅收起当前弹窗。

## Google 更新后，减少手动排障

已经通过 StepX 安装适配的 Google 服务，组件更新后会由手机自动检查权限和登录服务。正常更新只做核验，发现已支持的权限缺口才恢复；保留已有账号和应用数据。

- **手机先处理：** 合并 Play 商店、Play 服务和 Google 服务框架的更新事件；短暂异常会延后重试，避免重复处理。
- **电脑补检查：** 连接稳定后独立后台核验，空闲时升级旧监控或恢复已支持的故障。与消息同步使用不同任务队列，通话和前台任务优先。
- **结果看得懂：** 小工具 → Google Play 显示正在检查、等待、恢复成功或需处理的原因。可暂停电脑维护、立即检查；正在执行的安全步骤完成后暂停。
- **不会无限修复：** 重试次数持久保存，重开客户端不会重置。旧监控升级按维护组件版本限制次数，部署失败不会反复重建手机网关。

旧监控首次升级使用既有适配工具，会短暂重建手机网关；后续手机原生更新监听直接工作。界面“服务检查通过”仅表示已核验的组件、权限及登录服务状态，不代表所有第三方应用都可用。

## 保留选择，明确边界

仅维护已核验设备、签名和安装来源的既有适配，不自动安装未安装的 Google 套件，不开启全局 USB 安装开关，不清空账号或应用数据。用户停用或暂停的组件保持原样。网络、账号和设备认证问题给出具体提示；Play Integrity、厂商认证及应用资格不能通过权限修复保证。

## 验证范围

- 162 项 Google Python 回归（含 48 个实际执行 Java 的模拟场景）、32 项 Rust Google 测试通过；模拟 Windows 无时区数据库的 25 项专项测试通过；界面实际点击暂停和恢复，并验证设置保存。
- 支持固件的真机纯无线、熄屏升级：手机返回新版运行回执，原生监控就绪；198 次消息状态、增量快照和通话状态读取无失败，95% 不超过 81 毫秒。
- 后续原生复检：网关、系统进程和开机标识保持不变，42 次并发接口读取无失败，95% 不超过 214 毫秒。

以上为这台设备本轮观测，升级阶段会重建一次网关；不等同于所有网络下的延迟保证。故障与连续组件更新用隔离模拟覆盖，本轮未重新安装 Google 套件、未制造账号故障，也未执行真实商店组件升级或手机重启。
