# 0.2.59 验证范围

本版对照公开 v0.2.50 审阅增量。新增应用商店、局域网投屏及设备只读信息；旧版功能不重复计为本轮新增或重新通过真机验收。

## 平台边界

| 平台 | 验证方式 | 未覆盖 |
| --- | --- | --- |
| Linux x64 | 核心与交互测试、实际 UI 渲染、PZ261A 实机投屏与设备读取 | 所有 Linux 发行版和显示驱动 |
| Windows x64 | GitHub 原生 runner 编译、测试、运行依赖与打包检查 | 实体 Windows 电脑的 USB 驱动和手机 GUI 联调 |
| macOS ARM / Intel | 分别在原生 runner 编译、测试、运行依赖与打包检查 | 实体 Mac 的图形界面及手机联调；Apple 公证 |

四平台均从发布提交构建；失败的目标不算验证通过。结果以本版关联的 GitHub Actions 为准。

## 重点回归

- 设备身份变化时停止操作；连接引导需要真实安装/权限/无线就绪条件。
- 缺失电池与硬件数据不填固定值，不从 SN 推断保修状态。
- 局域网投屏路径要求会话凭证；错误/过期凭证拒绝；控制只接受 POST，默认仅观看；静止帧不重复发送或虚报 FPS。
- APK 校验包名和签名；商店不静默下载其他应用，不自动卸载以完成降级。
- UI 使用项目内演示模式截图，展示数据为虚构，不用于认证真机功能。

## 已知限制

支持设备主要为 PZ261A。高级固件适配范围、Google 服务认证限制、手机首次解锁要求延续 0.2.50。局域网浏览器接收依赖防火墙和设备互访；DLNA / 旧版 AirPlay 尚未覆盖全部电视，Google Cast V2 会话未实现。
