## 重点回归

- 设备身份变化时停止操作；连接引导需要真实安装/权限/无线就绪条件。
- 缺失电池与硬件数据不填固定值，不从 SN 推断保修状态。
- 局域网投屏路径要求会话凭证；错误/过期凭证拒绝；控制只接受 POST，默认仅观看；静止帧不重复发送或虚报 FPS。
- APK 校验包名和签名；商店不静默下载其他应用，不自动卸载以完成降级。
- UI 使用项目内演示模式截图，展示数据为虚构，不用于认证真机功能。

## 已知限制

支持设备主要为 PZ261A。高级固件适配范围、Google 服务认证限制、手机首次解锁要求延续 0.2.50。局域网浏览器接收依赖防火墙和设备互访；DLNA / 旧版 AirPlay 尚未覆盖全部电视，Google Cast V2 会话未实现。
