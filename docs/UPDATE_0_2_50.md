# 0.2.25 → 0.2.50：这次升级在哪里

比较基线为 GitHub 已发布的 `v0.2.25`。0.2.26—0.2.49 的开发变更一并收录；这些版本号不表示每个版本都有公开安装包。

| 场景 | 0.2.25 已有 | 0.2.50 的重点变化 |
| --- | --- | --- |
| 聊 Amoo | 默认聊天，手动选择文件、图片、应用流程 | 流式回复、任务识别与改回聊天，任务和会话衔接，技能/记忆/模型入口集中 |
| 做完后再改 | 输出文件与应用预览 | 成果卡片继续编辑、对话内关联成果；工作目录丢失时不再直接报文件不存在 |
| 手机操作 | GUI 控制与原生执行器适配入口 | 会话中显示操作进度小窗；切换会话、暂停/继续/停止后状态清理 |
| 找照片 | 文件目录和扩容记录 | 独立相册、类型/来源筛选、电脑已迁移原件联动；隐藏内部文件 |
| 日程 | Amoo 定时任务 | 手机日历与闹钟独立页面；与 Amoo 任务入口区分 |
| 无线连接 | 配对与已信任设备 | 扫码入口修复、mDNS 动态端口重连、多连接通道切换与适配固件的开机恢复 |
| 日常管理 | 短信、电话、文件、应用、投屏 | 列表信息、右键操作、图标、状态和确认交互继续整理 |
| Google 服务 | 安装与兼容性检查 | 组件/权限/账号登录/设备证明分别诊断，保留失败原因，不误报“认证成功” |
| 响应与发布 | 按需绘制、简洁窗口、便携依赖 | 对话/大任务通道分开、缓存与刷新优化；隔离真实设备测试与开发机路径 |

## 先看实测性能

同机真机比较，Amoo 连续会话读取中位耗时 **730 → 345 ms，减少约 53%**；电话基础信息读取 **402 → 275 ms，减少约 31%**。启动窗口出现时间基本持平。数据来自 Linux + PZ261A 的指定测试条件，不代表模型生成或全应用提速；[方法与全部测量结果](PERFORMANCE_0_2_50.md)公开可查。

## 从用户能感受到的变化看这次更新

### 1. 不用先理解 Work、Studio 和各种能力的区别

0.2.25 已经提供统一 Amoo 入口。本次继续把会话、技能、记忆、模型与成果衔接起来：普通提问保持聊天，处理资料时切换任务，做过的小应用从「我的作品」继续找。价值在于减少寻找入口和重新说明上下文，而不是简单增加菜单。

### 2. 对话更连续，等待时知道正在做什么

支持手机增量回复的会话会边生成边显示；工具执行过程默认收起，结果保持可读。简洁小窗增加剪贴板提问等快捷操作；本轮回归补上未发送草稿的会话切换保存，避免写了一半重新输入。手机未返回增量时，不承诺所有模型都实时逐字输出。

### 3. 成果不是一次性下载，做完可以接着改

文件、图片、小应用的结果与当前任务关联，可预览、继续编辑、打开位置或发送手机。修复应用继续编辑时工作目录缺失导致的报错。用户得到的是“提出需求—看结果—提修改—交付”的连续过程；应用在伴侣离线作品库使用，Studio 云端能力仍以官方服务状态为准。

### 4. 找照片与找电脑原件，少翻几层目录

新增独立相册，照片、视频及来源筛选更直观；过滤内部缩略图等干扰项，并关联电脑上已迁移的原件。存储扩容已有，本版重点是缩略图/清单浏览、日期分组和文件状态。迁移仍需用户确认规则，保存和校验完成后才清理手机原件；不把离线文件显示成随时可访问。

### 5. 手机日常事务，有清楚的位置

手机日历与闹钟有独立页面，与 Amoo 的定时任务区分。消息、通知和电话集中处理，验证码、链接及可回复入口更容易找到。文件与应用的常用操作继续统一；通知能否回复取决于应用和授权，不把快捷回复失效误报成已发送。

### 6. 连接过的设备，尽量少让用户重新设置

修复扫码入口，完善 mDNS 动态端口发现、同一手机的 USB/无线通道切换和短暂断线恢复。已适配固件补齐开机后服务恢复，状态区分“首次解锁”“恢复中”“需要修复”。首次配对和 Android 重启后首次解锁仍需本人完成；访客 Wi-Fi、防火墙和网络隔离会影响自动连接。

### 7. 原有特色继续完善，遇到限制也能看懂

背屏设置和体感游戏、空间压缩、投屏与控制栏、Google Play 安装均为已有能力。本次整理状态、反馈和诊断。Google 基础组件、权限、登录和设备认证分别显示，不再用某一层成功代表所有 App 均可登录。

### 8. 更新包更适合普通电脑，验证范围透明

保留随包 ADB、scrcpy、Python、Java 与 APK 校验工具，核对中文和空格目录。Windows、macOS 两种架构及 Linux 分别构建。本轮发现并修复 macOS 路径别名引起的预览失败；9 种窗口尺寸覆盖输入、附件、预览和草稿。原生 CI 验证不等于每一种电脑与手机组合都已实测。

## 不应误解为本次新增

空间压缩、背屏游戏、Office 生成、图片生成、简洁模式、Google Play 安装以及内置更新器在 0.2.25 或更早版本已存在。新视频会强调升级差异，不把这些已有能力包装为全部新功能。

## 已知限制

Amoo 服务、模型权限和手机授权由原厂与账号决定；Studio 云预览与普通对话自动委派 Neo 不声明全面通过。X 原生 Google 登录的设备证明问题仍在。未经认证的机型不会因为安装本项目而自动取得 Google 认证。
