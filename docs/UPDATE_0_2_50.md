# 0.2.25 → 0.2.50：这次升级在哪里

比较基线为 GitHub 已发布的 `v0.2.25`。0.2.26—0.2.49 的开发变更一并收录；这些版本号不表示每个版本都有公开安装包。

| 场景 | 0.2.25 已有 | 0.2.50 的重点变化 |
| --- | --- | --- |
| 聊 Amoo | 默认聊天，手动选择文件、图片、应用流程 | 流式回复、任务识别与改回聊天，任务和会话衔接，技能/记忆/模型入口集中 |
| 做完后再改 | 输出文件与应用预览 | 成果卡片继续编辑、对话内关联成果；工作目录丢失时不再直接报文件不存在 |
| 手机操作 | GUI 控制与原生执行器适配入口 | 会话中显示操作进度小窗；切换会话、暂停/继续/停止后状态清理 |
| 找照片 | 文件目录和扩容记录 | 独立相册、类型/来源筛选、电脑已迁移原件联动；隐藏内部文件 |
| 日程 | Amoo 定时任务 | 手机日历与闹钟独立页面；与 Amoo 任务入口区分 |
| 无线连接 | 配对与已信任设备 | 扫码入口修复、mDNS 动态端口重连、多连接通道切换与适配固件的开机恢复 |
| 日常管理 | 短信、电话、文件、应用、投屏 | 列表信息、右键操作、图标、状态和确认交互继续整理 |
| Google 服务 | 安装与兼容性检查 | 组件/权限/账号登录/设备证明分别诊断，保留失败原因，不误报“认证成功” |
| 响应与发布 | 按需绘制、简洁窗口、便携依赖 | 对话/大任务通道分开、缓存与刷新优化；隔离真实设备测试与开发机路径 |

## 适合分享的介绍

**Amoo 不止聊完就结束。** 新版可以围绕图片、文档和小应用继续修改，预览成果，再发回手机。相册、日历、闹钟和自动重连补齐日常使用；背屏设置、体感游戏、空间压缩、文件互传、投屏控制与 Google Play 安装继续保留。

下载：<https://github.com/xydzf520/stepx/releases/tag/v0.2.50>

## 不应误解为本次新增

空间压缩、背屏游戏、Office 生成、图片生成、简洁模式、Google Play 安装以及内置更新器在 0.2.25 或更早版本已存在。新视频会强调升级差异，不把这些已有能力包装为全部新功能。

## 已知限制

Amoo 服务、模型权限和手机授权由原厂与账号决定；Studio 云预览与普通对话自动委派 Neo 不声明全面通过。X 原生 Google 登录的设备证明问题仍在。未经认证的机型不会因为安装本项目而自动取得 Google 认证。
