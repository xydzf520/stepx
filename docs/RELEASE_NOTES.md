# StepX Companion 0.2.60

本次修复应用下载后无法安装，以及“安装包已准备好，但点击安装只出现笼统红字”的更新交互。

## 修复内容

- **支付宝等应用下载后安装失败**：修正 APK 校验工具的参数顺序，解决 `EOF while parsing a value`。应用商店与本地 APK 安装共用此修复；保留包名和签名校验。
- 校验失败显示具体原因，不再一律提示重新解压；四平台打包检查增加客户端实际使用的校验流程，覆盖中文路径和被修改的 APK。
- 明确列出阻止重启的具体任务、未发送草稿、待发送附件或未保存设置；每项提供“前往处理”。
- 下载成功与重启条件分开显示；处理完成后自动恢复“安装并重启”，安装包继续保留，无需重复下载。
- 已完成 Studio 创作并记录到作品的原始描述不再当作未提交草稿；修改后的描述仍保留检查。
- 补齐后台 Amoo 回复、应用下载/安装、消息发送及文件交付期间的重启保护，切换页面不会绕过。
- 返回设置处理时保留尚未保存的更改；不会自动发送或清空草稿。

## 从旧版升级

如果旧版仍卡在这条笼统提示，可先保存重要草稿、完成正在执行的任务，再退出客户端，将新版**完整解压到新目录**后启动。设置与个人数据保存在用户目录，不需要清除账号数据。仅替换一个可执行文件会缺少运行依赖，请保留整个安装目录。

提供 Windows x64、macOS ARM64 / Intel、Linux x64 四种包；内含 ADB 和所需运行依赖。手机伴侣仍为 0.1.32。

Windows / macOS 的原生 CI 构建、测试和包检查不代表所有实体电脑均已联调；macOS 未 Apple 公证，Windows 无商业代码签名。主要面向 STEPX Neo / PZ261A，功能范围与固件限制延续 0.2.59。
