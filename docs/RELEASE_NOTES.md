## 可靠性与性能

- 消息同步与 AI 生成分队列，断线重连核对实际读取，避免仅显示在线却停滞。
- SQLite 事务、索引、增量写入与分页，缩略图和字体缓存，减少重复处理；不同数据规模和操作的收益不同。
- 宽窗口首页按模块可用宽高取核心内容，拖动与缩放减少布局重算，保留用户编辑草稿。
- 电量与充电状态随已有消息快照更新，广播缓存和有节制的补读，避免单独高频轮询。
- macOS 文件选择与保存统一隔离进程、异步续办，规避后台 AppKit 创建窗口与模态事件重入。
- Windows 历史数据库路径原子迁移，保留已有记录；短暂文件占用有限重试，失败不先删原文件。macOS 延迟和分包连接不再提前结束读取。
- 公共源码与安装包使用明确资源清单，排除开发机设备记录、运行数据库、日志、截图、备份和凭据。
