## 这次能感受到什么

- **应用商店**：在电脑分类浏览、搜索应用，查看详情、截图与来源；结合手机已安装列表检查更新，下载 APK 或安装到当前手机。上游商店的下载和版本可用性可能变化。
- **局域网投屏**：手机连接电脑后，同一局域网的另一台设备可通过浏览器打开本次投屏链接或扫码观看。支持切换画质；默认仅观看，需要时在电脑明确开启远端操作。结束投屏后旧链接失效。
- **减少无效开销**：静止投屏不再反复发送同一张 JPEG；帧率来自实际采集。此项针对局域网投屏路径，不代表整个应用或模型回复提速百分比。
- **首页更集中**：整理设备状态和投屏快捷入口；补充手机能够提供的电池健康、充电循环、容量、温度与固件信息。未读取到的项目明确显示未知，不再补入固定值，也不凭序列号断言仍在保修期。
- **Amoo 查询设备信息**：询问电池健康、温度或硬件信息时，附加设备只读快照，减少不必要的打开设置操作；无法读取和官方保修状态会明确说明。保留系统真实锁屏状态，不通过伪装解锁绕过系统检查。
- **安装与连接反馈**：修复连接引导在伴侣权限尚未就绪时误判可继续；保留 USB / 已授权无线通道的设备身份核对，阻止操作被重新分配给其他手机的连接。

## 发布前修复

- APK 下载与安装前核对包名和签名；安装使用已校验的不可变副本。禁止把其他搜索结果当成目标应用，不再静默切换商店或把固定历史包链接换成最新版。
- 历史版本被 Android 拒绝覆盖时说明原因，不自动卸载原应用或清除数据。
- 局域网投屏使用每次启动更新的随机访问凭证，限制请求大小和连接数；控制接口只接受 POST，执行失败返回错误。
- 删除固定帧率、固定电池数据与未经查询的保修结论；缺失 HLS 分片返回缺失，不发送不对应的片段。

## 下载与升级

提供 Windows x64、macOS Apple Silicon、macOS Intel、Linux x64 四种包。**完整解压**，保留 tools、runtime、scripts 等目录。内含 ADB、scrcpy、Python、Java 和 APK 校验工具，不需要预装 Android Studio；每包附 SHA-256。

已有用户可使用客户端 GitHub 更新入口。手机伴侣仍为 **0.1.32**，本轮主要更新桌面端与桥接组件；不会把桌面版本号当成手机 APK 版本号。

## 验证范围与限制

- 客户端主要面向 **STEPX Neo / PZ261A**，普通 Android 未列为支持设备；高级权限适配仍限定已核对的固件。
- 浏览器接收是本轮重点验证路径。DLNA、旧版 AirPlay 为实验性接收适配，发现设备不代表播放成功；**没有实现 Google Cast V2 媒体会话**，不宣称所有电视都能一键投屏。
- 局域网投屏依赖电脑持续运行和网络设备互访。手机锁屏、路由器隔离、防火墙及授权状态会影响可用性；接收链接只应分享给信任的人。
- Windows / macOS 通过原生 CI 测试和打包后提供下载；这不等于每一种实体电脑都完成手机联调。macOS 未 Apple 公证，Windows 无商业代码签名；Linux 构建基线为 Ubuntu 24.04。
- Google Play 安装不等于机型获得 Google 认证，X 原生 Google 登录的设备证明问题未声明解决。
