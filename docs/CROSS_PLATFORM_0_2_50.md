# 0.2.50 兼容性与验证

比较：GitHub v0.2.25 → 当前 0.2.50。验证日期：2026-10-26—27。构建结果与实际设备测试分别记录。

## 电脑平台

| 平台 | 发布目标 | 验证范围与条件 |
| --- | --- | --- |
| Windows | x64 | 原生 CI：核心、界面状态、更新器、Chrome/Edge、本体及便携运行时；需要厂商 USB 驱动时仍需安装，暂无实体 Windows 手机联调覆盖 |
| macOS | Apple Silicon / Intel 独立包 | macOS 15 原生 CI，.app 资源路径及 ad-hoc 签名；未做旧 macOS 或实体 Mac 手机联调，不含 Apple 公证 |
| Linux | x64 | Ubuntu 24.04 CI；当前 Linux 桌面与 PZ261A 设备验证；发布包需要 glibc 2.39+，旧发行版请从源码构建 |

正式包包含 ADB、scrcpy、Python、Java 和 APK 校验依赖。保持完整目录；中文和空格路径纳入打包检查。本机应用生成/验证及 Studio 网页会话需要 Chrome / Edge / Chromium；普通对话不需要额外浏览器。macOS 屏幕截图、麦克风等仍需系统授权；各平台中文朗读取决于系统语音。

## 手机范围

| 设备 | 可用范围 | 不保证的能力 |
| --- | --- | --- |
| PZ261A，Android 16 / 172 | 本机主要测试目标；Amoo、背屏、伴侣、系统适配 | 原厂云端的所有模型/账号、所有第三方 App 登录 |
| 另一台同固件 PZ261A | 程序按用户选择的设备身份执行，不绑定开发者序列号；须重新授权/配对 | 尚无第二台同固件设备的完整端到端覆盖 |
| 不同 STEPX 固件 | 先读取版本与能力；高级写入需通过固件、SDK、ABI 与原生库校验 | 不承诺兼容未知 OTA；不跳过校验强行安装 |
| 普通 Android | 当前客户端识别仅接受 STEPX / PZ261A / pandora，不列入支持范围；ADB、scrcpy 可作为独立工具使用 | 不支持直接套用本客户端的手机功能与专有服务 |

伴侣最低 Android 13。无线配对通常需要 Android 11+；网络隔离、防火墙和 mDNS 限制会影响自动发现。重启后首次解锁为 Android 要求；首次配对/权限确认不能省略。公开 APK 不含 Neo 上游执行引擎。

## 本轮修复与验证记录

- 清理四项依赖特定相册、固定序列号和开发机目录的测试，改为显式选择设备的只读验收；普通单元测试不写个人会话。
- 截图验收程序仅编入测试功能构建，不进入正式发行版；保留公开 UI 框架已有 macOS Clipboard 适配。
- 移除系统维护脚本默认指向开发者手机的行为，要求明确选择设备。
- 本机自动化：Rust 核心 279 通过 / 1 忽略，契约 25 通过，桌面交互状态 101 通过 / 2 忽略，Python 403 通过；开机恢复/重连/运行时另 15 项通过。
- 窗口回归：简洁与完整模式共 9 种尺寸（360×480 至 1600×1000），长中文输入、图片/CSV 预览、混合附件、会话与草稿切换全部通过；欢迎页输入框位移为 0。
- 修复未发送的新会话草稿在切换时丢失，以及 macOS 临时目录路径别名导致合法文件无法预览的问题；工作目录内部的符号链接仍被拒绝。
- 本轮 Linux 图形界面 + 真机 Amoo：点击输入框并按回车发送，计算 7×8 回复 56；拖入图片正确识别三种颜色和图形；拖入中文/空格文件名 CSV，返回 36、32 与总额 68。测试通过真实界面事件完成，非仅调用测试接口。
- 四个原生构建目标均已完成核心/界面测试、浏览器/更新器运行时测试、Release 编译、便携打包和包内工具烟测。[本轮 GitHub Actions](https://github.com/xydzf520/stepx/actions/runs/40353027182) 的代码版本为 `0216ce89518e9e9a8ee90ed9211963d699f2b103`。后续提交仅更新说明、视频封面和测试数据。
- 已下载 Linux 发布包，SHA-256 与生成值一致；在未提供 Android SDK、Java/Python 安装环境的启动检查中，通过 `--version`、`--check-runtime` 和实际窗口启动。Windows/macOS 原生运行验证在对应 CI 完成，下载后再检查压缩包完整性与 SHA-256。
- 性能对照使用相同 Linux / PZ261A / USB：Amoo 连续会话读取中位耗时 730.13 → 345.48 ms，电话基础信息读取 401.82 → 275.43 ms；各 9 次。启动窗口出现时间基本持平。详见 [全部方法与数据](PERFORMANCE_0_2_50.md)，不等同全应用或模型生成速度。
