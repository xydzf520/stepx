## 哪些边界不能省略

- **消息与搜索**：已同步通知不是完整聊天历史；手机文件通常按名称搜索，电脑指定目录可检索支持的文本。
- **AI**：手机账号与独立 API 按所选来源调用；不额外赠送额度。Agent 的建议、草稿和文件生成不等于用户任务已完成。
- **熄屏与 GUI**：已授权后台读取可继续；重启后首次密码解锁、原厂安全确认和需要可见界面的操作仍需用户完成。
- **电话**：双向电脑音频的验证范围为项目记录中的支持手机与 Linux 组合，不推广到所有 Windows / macOS 电脑。
- **MCP**：优先使用手机实际公开的接口，不代表任意 App 数据都能读取或所有动作都能在后台完成。
- **语音**：原厂通用离线转写与语音合成尚未验证可调用，不能把云端服务或能力检查写成可用的端侧语音。
- **性能**：局部增量和缓存已有收益，完整快照、全量关联与初次加载仍有成本；页面分批显示不等于协议或 SQL 全部分页。
- **跨平台**：修复、构建通过与真实设备验收分开说明；macOS 包为 ad-hoc 签名，未 Apple 公证。
