# StepX Companion

### 以人为中心，让 AI 贯通终端与服务。

连接手机与电脑上的消息、文件、安排、工具与 AI 成果，让提醒及时到达，让工作与生活跨端继续。

Linux / macOS / Windows · Rust 原生客户端 · 面向 STEPX Neo / PZ261A

[下载安装](https://github.com/xydzf520/stepx/releases/latest) · [快速开始](docs/GETTING_STARTED.md) · [更新日志](CHANGELOG.md) · [反馈问题](https://github.com/xydzf520/stepx/issues)

</div>

面向 STEPX 用户的社区项目，与 STEPX、Amoo、Google 无官方隶属关系。普通 Android 不在本版支持范围；原厂专有能力仍依赖对应固件、权限和账号。

## 先看你最常用的几个场景

| 你在做什么 | StepX 怎么帮你 |
| --- | --- |
| 正在写文档，手机又有新消息 | 右下角独立提醒不抢输入焦点；验证码一键复制，最新消息优先，红包有独立样式。可暂不提醒、按应用关闭，或清理本次弹窗。 |
| 等快递、怕漏会议和未接电话 | 顶部实况胶囊集中显示仍需处理的事。规则先判断，Agent 可辅助复核；证据不足保留未知，取件和已完成事项及时收起。 |
| 早上想知道今天怎么安排 | 首页完整月历排第一，工作与生活用两种颜色标记。16 个模块可调整顺序、大小和显隐，编辑支持撤销与取消。 |
| 刚生成 PDF、保存图片或拍了照片 | 首页和「文件与扩容」都能看到最近文件。电脑与手机合并查看，打开、传到手机或保存到电脑，不限定来源软件。 |
| 忘记消息或资料放在哪里 | `Ctrl K` 打开先看最近文件，输入关键词统一查找；综合 / 手机 / 电脑按需筛选，按消息、文件、Amoo、日历、功能等分类定位。 |

| 讨论结束，需要真正的成果 | 沿用手机账号的可用 AI 能力，整理方案、待办和日 / 周 / 月回顾，关联依据，再把文件送回手机继续用。 |

## 公开版 0.2.60 → 0.2.180

本次累计更新覆盖桌面提醒、胶囊、首页、最近文件、搜索、消息电话、AI 成果、日程与手机工具；[按用户场景查看全部更新](docs/RELEASE_0_2_180.md)。客户端的图文说明可随时从 **设置 → 关于** 再次打开。

性能优化集中在减少重复处理与等待，已有两组可核对的对比：

| 测试场景 | 修改前 → 修改后 | 如何理解 |
| --- | --- | --- |
| 2 万条记录中修改 1,000 条，热快照持久写入 | 44.054 → 8.545 ms（中位数） | 比旧 SQLite 实现约快 5.16 倍；仍慢于同轮 JSON 的 3.887 ms |
| 1,000 个任务中保存一份草稿，含克隆、比较与提交 | 1.569 → 0.474 ms（中位数） | 处理成本约降为原来的 30%；不含原有捕获及合并等待时间 |

以上为 0.2.154 集成的同机、合成数据对比，保留持久化要求；不能推导整机、所有页面或网络同步的统一提速。0.2.180 在 6 种宽高下验证首页布局和交互，并对 30 个视图构造场景做性能检查；视图构造耗时不是 GPU 帧率或端到端延迟。[数据、方法与限制](docs/PERFORMANCE.md) · [写入原始对比](docs/storage-batch-performance-0.2.154.md)。

**0.2.178–0.2.180 最新变化**：打开搜索直接看到最近文件；首页按实际宽高调整内容，同排卡片底边对齐、独占一行时利用可用空间，保留所选尺寸与模块。尺寸可点击选择或拖动调整，移动、隐藏和场景选择都有明确反馈。此前的 macOS 文件窗口隔离、弹窗批次清理与发布资源检查继续保留。各平台包以发布页实际可下载内容为准。

### 能力边界，先说清楚

- **电脑接听**：已有 Linux + 支持固件的纯无线双向通话实测；可选择手机接听、挂断和回拨。尚不能将结果推广为 Windows / macOS 全面音频兼容。
- **消息**：检索和呈现的是已同步内容；通知来源不等于微信全量聊天历史。后台回复需要手机提供可用的通知回复入口。
- **搜索**：手机文件与图片主要按名称检索；电脑指定目录可检索支持的文本内容，不代表任意文件内容均能解析。
- **手机 AI**：遵循当前账号与模型的实际权限、额度和计量。GUI 执行模型可能单独配置；未将云端语音当作手机端侧语音，原厂通用离线 ASR / TTS 尚未开放验证。
- **macOS 修复**：代码与构建检查不替代苹果实体设备验收；安装包使用 ad-hoc 签名，未 Apple 公证。

发布包提供 **ADB、scrcpy、Python、Java 与 APK 校验工具**，无需预装 Android Studio。请完整解压，不要只复制可执行文件。每个包附 SHA-256；Windows/macOS 的原生构建与运行时验证不等于所有实体电脑均已联调。[0.2.180 更新与使用条件](docs/RELEASE_0_2_180.md) · [历史跨平台验证记录（0.2.59）](docs/CROSS_PLATFORM_0_2_59.md)

主要设备为 PZ261A；高级权限/重启恢复适配 Android 16 / 172 固件，未知固件不跳过检查强装。普通 Android 目前会被客户端设备识别拦截，不列入支持范围；手机伴侣最低 Android 13。同局域网自动发现需要设备互访和 mDNS，防火墙或访客网络隔离可能阻止连接。

## 快速开始

1. 下载对应电脑架构的完整包，解压运行。
2. 按新手弹窗开启手机开发者选项、USB 调试，连接数据线并在手机授权。
3. 在「连接设备」选择手机，按需安装 StepX伴侣并确认所需权限。
4. 需要无线连接时，在同一可信局域网完成一次扫码或数字配对。
5. 进入 Amoo 聊天，或使用文件、相册、背屏和小工具。通过「设置」调整目录、快捷键、外观及自有模型。

[详细步骤](docs/GETTING_STARTED.md) · [存储扩容](docs/STORAGE_EXPANSION.md) · [Amoo 工作区](docs/AMOO_WORKSPACE.md)

## 数据留在你的用户目录

公开源码与安装包只带运行程序、资源和必要工具，不带开发机的聊天、数据库、设备记录、截图、日志、备份或模型密钥。0.2.153/0.2.154 将主要业务存储迁入 SQLite 事务、增量保存和搜索索引，提供校验备份及恢复；部分页面仍会读取完整快照，具体接入状态见 [数据消费者清单](docs/storage-consumer-integration-0.2.154.md)。软件正常使用需要保存自己的设置、同步缓存与文件；这些数据留在当前电脑的用户目录，并不因为项目开源而上传到 GitHub。

向模型生成内容、给手机传输文件等功能仍会按你启用的服务发送所需内容。清理缓存、删除记录和迁移原文件是不同操作，具体范围在设置与操作确认中说明。排障日志请先脱敏再提交。

## 开发与贡献

```sh
git clone https://github.com/xydzf520/stepx.git
cd stepx
cargo build --release --locked --manifest-path desktop/Cargo.toml
```

UI 依赖已放在 `vendor/`。系统依赖、Android 构建和打包见 [构建指南](docs/BUILDING.md)。欢迎提交复现步骤、跨平台问题和 Pull Request。
